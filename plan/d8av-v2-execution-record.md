**Implement.** `src/ui/replay-visual.ts` holds presentation-only geometry: `replayX`, `replayY` (clamped between Stop and Target), `splitSegments` (from advisory decomposition only), `sparkline` (one point per supplied advisory value; gaps omitted). `src/ui/replay-view.tsx` renders the Corridor replay as its own view: sticky control bar (Price action segmented control, step buttons, slider, session label, six visualization tabs with only Corridor enabled), Corridor SVG with two rails, gap bands, observed Mark dots and a click-to-seek cursor, result-coloured status strip, move line with a named underlying/time/volatility split bar, IV and share-equivalent chips with popover sparklines labelled Estimate, plan line, sticky readout with kv groups, and an every-session table with a Plan row and explicit `—` gaps. `src/ui/detail-controller.ts` exposes read-only `advisorySeries` (one estimate per session that has a Mark) so popovers show real values rather than invented ones.

**Removal and test migration.** The bare range slider, flat session-timeline list and plain advisory text block were deleted from the complete-detail card; replay is reached through an explicit `Open replay` button in the Journal drawer. Three existing D8a scenarios were migrated rather than dropped: session-by-session seeking and explicit gaps now assert against the replay slider and session table; the advisory scenario asserts chips, popovers and the readout split; the read-only scenario opens replay before seeking. One V1 cockpit assertion on the deleted timeline was migrated to the `Open replay` control.
