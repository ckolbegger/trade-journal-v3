# T95.18-F1 ReviewCards intermittent failure

Test fix. Rows are single-case runs; this task is a flake fix, so no red/green case row applies.

## Before
npx vitest run src/ui/screens, 4 runs on the T95.18 base: 3 failed, 1 passed (the same case each time: "card list (A150) ... should render one card per walked Trade ...").

## Cause
The failing line asked ABC's open card for its meter (getByRole img) straight after waiting only for the headers. The open card's body is filled by an asynchronous DailyReview.getTrade, so the Now box is not there yet when the machine is busy. The failure dump shows the card open (aria-expanded true) with no img at all. Test race, not a product bug; no timeout was raised.

## Fix
src/ui/screens/ReviewCards.test.tsx: that getByRole became await findByRole.
