## B4.10: product defect, reported, test left as written

In Recovery Only, ABC's Mark for the Review Date is missing, so the Action panel reads "No Action until today's Mark is in. Enter it", with a link to the Marks step. In Recovery Only the Marks step offers no Price field and no "Can't get a price" (the same case asserts this), so the link leads nowhere usable and the words mislead. `ActionForm.tsx` line 194 (`if (toGo > 0) return <MarksFirst .../>`) runs before line 195 (`readOnlyEmpty && form.kind === 'New'` returns "No Action saved."). A product fix is needed (a read-only runtime should show "No Action saved." and no link); the test expectation was not changed to accept the link.
