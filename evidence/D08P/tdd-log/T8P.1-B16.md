Probe before the design (macOS, this user): `ps -E` shows another process's environment for node and for the detached node child that Playwright-style `spawn(..., {detached: true})` creates (the token survives the reparenting to PID 1), but not for Apple system binaries (`/bin/sleep`, `/usr/bin/perl`) or a copy of `sleep`. So the environment token finds orphaned node and browser processes, and a periodic scan (about once a second, a ps of about 30 ms) with start-time identity covers the rest. A system binary that is born and loses its parent within one scan interval can still be missed; the script's header says so.

Notes:
- The new test passes against the orig script for case 3's masked-window test (orig already blocks signals), as expected; only the scratch without the blocking fails it.
- Design change the case 3 test needed: `TJ_BROWSER_LOCK_TEST_CHILD_PAUSE` now holds the child inside the masked window (before it resets the handlers and unblocks), not after, because a parent-only pause cannot show a difference: the wrapper's handler only records a signal, so a TERM sent to the wrapper alone gives 143 with or without the blocking.
