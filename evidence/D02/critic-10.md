## 4. Minor observations
1. **Caption inset:** the narrow table caption starts at the region's left edge (x 16), while the header and cell text start at x 26. This was so before T2.67 too; it is cosmetic.
2. **Firefox setup:** with the mismatched Firefox 157 build, Playwright's `locator.check()` on a visually hidden chip radio timed out inside the `recordEntry` helper. Clicking the chip's label worked. This is a tooling and version mismatch, not an app observation.
3. **WebKit:** headless WebKit 26.6 reports Unsupported on the capacity check, so the U10d check could not run in WebKit.
4. **Bullets in Deviations:** the Deviations card still renders a bulleted `<ul>`. U9i only forbids the badge, so this is not a failed condition.
5. **DEF fixture row:** "Long 100 shares @ $50.00 · Records disagree" in Planned, and its Detail still offers "Record entry", as critic-9 noted. This follows only from the fixture.
6. **Recovery Only fault:** the fault applies only while `?faults=inventory` is in the URL. A plain navigation to `/record-entry` without it showed the writable form. That is the faults harness, not the product.
7. **Receipt at 320:** the receipt heading wraps before the date ("POSITION CHANGE AT / 2026-10-12 10:00"). That is allowed, since the date and time stay together.
