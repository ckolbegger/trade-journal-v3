## 4. Minor observations (not defects)
1. **Next card opens with its header out of view.** After an Action save, or after following a Missing-Mark link, the opened card is shown by focusing its first Price input, not by scrolling its header under the page header.
   - Example: after T-A's Action save, T-B's header sat at y = −219 px.
   - The trader therefore sees the ABC row, not the card's header (the Trade's name and summary) or its figures.
   - A151's scroll-to-header rule covers header presses only, so this is not a failed condition. It is weaker than story 6's "take me to the next position", especially when two Trades share an Underlying.
2. **Which card comes next.** With several cards missing a Mark, the next step goes to the first Missing Mark in Instrument order (ABC, so T-B), not the first such card in attention order.
   - The list order was T-E, T-C, T-B, T-F, T-A, so the Review jumped to the middle of the list.
   - P36 only says the next step "prefers a card with a Missing current Mark", and A68 says "first … in attention order, starting from the current one". Both readings are possible, so this is a point to confirm, not a failure.
3. **Two hold messages at once.** After an Action save on a held card, pressing another header shows both "Save or discard what you entered for XYZ (Long 100 shares @ $50.18) to leave it." and "The Action is saved. Save or discard … to go on." at the same time.
4. **Leaving through the main navigation drops a draft silently.** Clicking Trades in the navigation while a draft Mark is typed leaves the Review with no prompt, and the draft is lost. Nothing is written (0 observations).
   - The UI contract allows this ("navigation without Save records no behavioral evidence"), and D1 A5 only defers update activation.
   - It differs from the in-Review hold, which blocks moving to another card.
5. **"At entry" appears only without a current Mark.** The open card shows the "At entry" group only when the Review-date Mark is missing (for example T-C, or T-A before Save Marks). T-A at XYZ 52.00 shows no "At entry" group.
   - A158 lists "then At entry"; T5R.11's T-A case at 52.00 reads the same way.
   - It looks like D4's conditional at-entry line, which A158 may allow ("when present"). Worth confirming the intent.
6. **"Today's Marks" headings repeat.** The Marks panel keeps D4's "Today's Marks" heading (level 3) under each card's Marks panel header (level 4), so the heading levels go backwards inside the open card. Axe did not flag it.
7. **Missing-Mark blocker for a shared Instrument.** "Mark missing for XYZ" links to T-A's card only (`?trade=<T-A>&instrument=XYZ`). This is acceptable, because the shared Mark resolves once from either card.
8. **Helpers:** every setup and probe helper I used worked; none failed.
