## Target-scale native observation

`implementation/evidence/d02/D2-final-identity-frozen-d2-scale.json` and `d02-benchmark.json` record the passing 25,000 historical D1 command-created Plan migration and 200 D2 Open Trades. Before/after normalized historical facts and membership have equal SHA-256 digests (50,005 source envelopes, 25,000 Trades). Source normalized evidence serialization is about 80.97 MB; it excludes physical envelope keys and is not the migration preflight's full snapshot byte count. The retained old generation and active candidate coexist; actual native origin quota/usage are in the raw record. No later domain facts were fabricated.

Normal verified update plus migration took 14,372 ms. CDP Runtime.getHeapUsage sampled every 100 ms after explicit old-page garbage collection measured a peak used JavaScript heap of **722,808,772 bytes**. This is a sampled heap observation on this macOS/Chromium host, not total RSS, a guaranteed maximum, a low-memory-device guarantee or an origin-quota allocation. Migration currently materializes the full source and candidate validation graph; it therefore has a substantial transient memory requirement at 25,000 Trades. Storage headroom and migration heap are separate quantities.
